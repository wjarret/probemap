# probemap

Modular machine-learning toolkit for RNA chemical probing data
(SHAPE-MaP, RING-MaP, RNP-MaP).

## Install

    pip install git+https://github.com/wjarret/probemap.git

## Status

Early development (BIOSTAT 615 final project, Track B).
